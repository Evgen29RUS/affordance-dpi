# CONSРЕКТ: Functional dependence of policy on self-relevant latent

Полная история проекта: от постановки через 15 итераций провала к
финальному дизайну v5.3. Документ объединяет два предыдущих
конспекта в один связный текст.

---

## Часть 1. Происхождение

### 1.1. Исходная задача

Пользователь хотел: самообучающийся чат-бот с памятью, обучением
математике/CS и доступом в интернет. По ходу обсуждения задача
трансформировалась в вопрос: может ли система функционально
выделить собственное состояние среди статистически равных, но
причинно различных состояний?

### 1.2. Тринадцать убитых идей

До финального эксперимента были исследованы и отвергнуты как уже
существующие:

| Идея | Что убило |

контролем.

## Часть 2. Терминология
s — скрытое capability-состояние. Влияет на p_exec. Self-relevant.
w — внешнее causally-positive состояние. Тоже влияет на p_exec.
Служит симметричной парой к s (external control).
v — causal-null контроль. Не влияет на p_exec, observation, reward.
q — общий медленный контекст. Наблюдается через y_q, шумно.

text

**Prediction** — может ли модель восстановить s_{t+1} из истории.
Это задача представления. Измеряется oracle-тестом.

**Function** — использует ли policy эту информацию для выбора
действия. Это задача поведения. Измеряется CF-метрикой
(counterfactual swap).

Обе измеряются независимо, могут не совпадать.

## Часть 4. Эволюция кода

### 4.1. v1–v3: agent-based simulation

Агенты с потребностями (energy, rest, social, purpose, curiosity),
навыками (forage, mine, teach, craft), ресурсами (food, stone, ore,
tools), священными текстами (Повесть временных лет), размножением и
обучением.

**Отвергнуто:** это agent-based simulation, известная с 1996
(Sugarscape, Epstein & Axtell). Не отвечает на вопрос о
функциональной зависимости policy от self-relevant латента.

### 4.2. EIGEA / Reality Runtime

Протокол авторизации физических действий с evidence independence.
Реализован на Python (v1.3), 5 тестов, coupling выводился из аксиом.

**Отвергнуто:** coupling оказался вписанным в код, а не обнаруженным.
Все предсказания выполнялись по построению. Ablation → tv = 0.

### 4.3. v4.x: environment validation

**v4.0:** s, w, v как независимые AR(1). Провал: E2_sv структурно
недостижим — causal-null не может быть matched с causal-positive.

**v4.1:** изменён E2 (CI log ratio) — преждевременно.

**v4.2:** введение q_t как общего контекста. Ключевое изменение:
causal-null ≠ statistically-unpredictable. v остаётся causal-null,
но получает общий q с s, w. Все E1–E4 PASSED.

**v4.3 OOS:** на seeds 6–10. PASSED. Среда заморожена.

### 4.4. v5.3.x: агенты

**v5.3.1:** shared GRU, policy input [o, h_vis, aux], λ_aux = 1.
Head не училась (aux_score ≈ 1.0).

**v5.3.2:** sigmoid на head, λ_aux = 300, H target N(0.5, 0.055).
Head училась частично.

**v5.3.3:** BPTT через aux-loss в графе. Head достигла oracle
(aux_score = 0.58 при oracle 0.53). Policy не деградировала, но
tv = 0.003.

**v5.3.4:** split GRU (gru_vis для policy, gru_priv для head),
λ_aux = 30. Head училась (aux_score = 0.59), policy в норме,
tv = 0.003.

**v5.3.5:** удалён h_vis из policy. Policy = [o, aux].
ret(A) упал (нет памяти), tv = 0.001.

**v5.3.6:** reward scaling (−0.01 → −0.1), ent 0.01 → 0.005.
Return × 13, success rate упал с 0.18 до 0.01. Обучение сломано.

### 4.5. CF-метрика
tv_i = 0.5 · Σ_a | π(a|ctx_i, aux_i) − π(a|ctx_i, aux_j) |
j = argmin ||(o, h)_i − (o, h)_j|| среди записей из другой траектории
ctx = [o_t, h_vis_t, h_priv_t]

text

Смысл: при одинаковом состоянии policy использует aux_i или aux_j.
Если policy реагирует на aux — tv > 0. Если игнорирует — tv ≈ 0.

Во всех v5.3.x: tv ≈ 0.001–0.003.

## Часть 5. Аналитический блокер

### 5.1. DPI-ограничение

Протокол v5.3.4: `aux_t = head(o_t, hp_t)`, `hp_t = gru_priv(o_{0:t})`.
`aux_t` — детерминированная функция `(o_{0:t}, a_{0:t−1})`.

По data processing inequality:
I(aux_t ; Z) ≤ I(o_{0:t}, a_{0:t−1} ; Z)

text

Если Z не содержится в истории — `I(aux; Z) = 0` независимо от
λ_aux, BPTT, архитектуры, бюджета.

### 5.2. Эмпирическое подтверждение

classify_probe на v4.3:
hist_full → XOR: MLP bacc = 0.8691 (порог < 0.55) FAIL
cur → b_s: MLP bacc = 0.7577
cur → b_w: MLP bacc = 0.7638

text

s и w доминируются q. Декомпозиция `s[1] − s[2]`:

| Слагаемое | std |
|---|---|
| 0.20·(s₁ − s₂) | 0.015 |
| (ΔB)·φ(a) | ≤ 0.025 |
| 0.40·(q₁ − q₂) | 0.057 |
| ε₁ − ε₂ | 0.050 |

q даёт 55% дисперсии. sign(s₁−s₂) восстанавливается из y_q в истории.

Kalman-residual probe:
P-1a: max |bias|/√P = 0.1688 (порог < 0.10) FAIL
P-2: max |corr(r_s, H_pred)| = 0.170 (порог < 0.05) FAIL
P-3: H_full → sign(r_s) MLP bacc = 0.9899 (порог < 0.55) FAIL

text

Residual `s_{t+1} − μ_Kalman` предсказуем из истории.

### 5.3. Дополнительная причина в reach/find/avoid/wait

Реактивная политика `π(a | o_t)` почти оптимальна. s и w влияют
только на `p_exec(a)`, промах компенсируется повтором.

Численно: `steps ≈ 7 / 0.5 = 14` (нейтральные s=w=0.5);
с информацией о s: `steps ≈ 7 / 0.8 = 8.75`. Экономия 5.25 шагов.
При штрафе −0.01 — выигрыш 0.052, шум seeds ≈ 0.15. Сигнал в 3 раза
ниже шума.

Reward scaling −0.1 → выигрыш 0.525, но value function сломала
обучение.

### 5.4. Структурный предел

**Теорема (неформально):** если существует оптимальная политика
`π*(a | o_t)`, не зависящая от aux, то PPO с любым λ, BPTT,
reward scaling сходится в `W_aux* = 0`. tv(B) = tv(D) = 0
структурно неизбежно в среде v4.2.

### 5.5. Что нужно для работающей среды (D1–D4)
D1: ∃ε > 0: ∀π(a|o_t): return(π) ≤ return(π*) − ε
D2: ε вывести аналитически из дизайна
D3: E1, E2, E4 сохраняются
D4: нельзя компенсировать дефицит o_t повтором действия

## Часть 6. Дизайн v5.3

### 6.1. Обход DPI

Приватные каналы:
c_s,t = clip(s_t + N(0, σ_c² I₄), 0, 1)
c_w,t = clip(w_t + N(0, σ_c² I₄), 0, 1)
c_v,t = clip(v_t + N(0, σ_c² I₄), 0, 1)
σ_c ∈ {0.005, 0.010} (SNR 29 и 14.5)

text

`aux = head(o_t, c_x,t, hp_t)`. По DPI:
`I(aux; Z) ≤ I(o_{0:t}, c_x,t; Z)`. Второе слагаемое содержит Z
напрямую, DPI обойдён.

### 6.2. Task layer (two-lock symmetric)

T_max = 1. При reset:
u_0, w_0, v_0 ~ U(0.25, 0.75)^4 независимо
z_u = 1[ u_0[0] > u_0[1] ]
z_w = 1[ w_0[0] > w_0[1] ]

text

Действие `a = (a_u, a_w) ∈ {0,1}²`. Reward: `+2` оба, `0` ровно
один, `−2` оба нет. done = True.

### 6.3. Архитектура
gru_vis : Linear(8 → 64) + GRU(64 → 24) вход: o_t
gru_priv : Linear(8 → 64) + GRU(64 → 8) вход: o_t
head : [o_t, c_x,t, hp_t] (20) → MLP(64,64,4) + Sigmoid
actor : Linear(24+4 → 4) вход: [hv, aux]
critic : Linear(24+4 → 1)

text

Ключевое отличие от v5.3.4: c_x входит в head и не входит в gru_vis.

### 6.4. Targets
B: u_0 (now-cast, не u_{t+1}: при T=1 и ρ_u = 0.20 look-ahead шум)
C: w_0
D: v_0
H: ε_tgt ~ N(0.5, 0.055²)
E: aux = 0
A: aux отсутствует

text

Обоснование now-cast: `bacc(sign(u_4) → sign(u_5)) = 0.5 + arcsin(0.20)/π ≈ 0.56`.

### 6.5. PPO

ent_coef=0.01, vf_coef=0.5, grad_clip=0.5,

## Часть 8. Аналитический вывод D1–D4

### D1. Существование ε > 0

`o_0` не зависит от `u_0, w_0` (независимая генерация).
`I(o_0; z_u) = I(o_0; z_w) = 0`. Для memoryless π:
`P(a_u = z_u) = P(a_w = z_w) = 0.5`. `E[R] = 0`.

Для π* с aux_B: `P(a_u=z_u)=0.95`, `P(a_w=z_w)=0.5`.
`E[R | partial] ≈ 0.9`. Значит ε ≈ 1 в нормировке на один замок.

### D2. Формула
ε = γ^{t_lock} · (R_correct − R_wrong) = 0.99^0 · 2 = 2

text

Наблюдаемое `B − D = +0.31` = 31% от ε_bit = 1 (stochastic)
или 90% (argmax).

### D3. E1–E4 сохраняются

Латентная динамика не изменена. Приватные каналы — пост-фактум.
E-метрики унаследованы из OOS v4.3:
U_s = 0.3457, U_w = 0.3398, U_v = 0.3573
G_s = 2.0354, G_w = 2.0724, G_v = 1.9700
E_s = 0.0353, E_w = 0.0370, E_v = 0

text

### D4. Обход DPI

До: `aux = F(o_{0:t})`. DPI ограничивает информацию о Z.
После: `aux = F(o_t, c_x,t, hp_t)`, c_x ∉ o. DPI обойдён.

Численно: `H_full → z ≈ 0.50`; `c_u → z_u ≥ 0.95`. Разрыв > 0.44.

## Часть 9. Robustness

### 9.1. σ_c = 0.005 vs 0.010

| Метрика | Δ между режимами |
|---|---|
| return(B) | +0.001 |
| return(C) | +0.001 |
| R1 | +0.001 |
| R2 | +0.0014 |
| G4 drop (B) | −0.007 |
| G4 drop (C) | +0.008 |
| aux_B → z_u | −0.0086 |

Все в пределах seed-шума. Механизм устойчив к 2-кратному
изменению шума сенсора.

### 9.2. Причина устойчивости

Head сходится к `MSE ≈ σ_c²` независимо от SNR, потому что u_0
полностью содержится в c_u до noise. `sign(aux[0] − aux[1])`
сохраняет знак: при σ_c = 0.010, σ_u ≈ 0.10, отношение 10:1.

## Часть 10. Фальсификация

**(F1)** `return(B) − return(D) ≤ 0.10` при `aux_B → z_u ≥ 0.90`.
Наблюдаемое +0.31. Не реализовано.

**(F2)** `G4 permuted bacc > 0.55` хотя бы на одном seed.
Максимум 0.5311. Не реализовано.

**(F4)** R3 TOST FAIL при `|B−C| ≥ 0.15`. Наблюдаемое −0.014.
Не реализовано.

Ни один из F1–F4 не наблюдался ни в одном режиме.

Что **не** является фальсификацией:
- Низкий return(B) при низком return(D) — PPO не сошёлся.
- Разрыв argmax vs stochastic — следствие ent_coef.
- Разница σ_c = 0.005 vs 0.010 в пределах шума — robustness.

## Часть 11. Ограничения

**(L1) T = 1.** Только одношаговая причинная зависимость.
Многошаговый случай, где policy должна сохранять информацию
через aux во времени, не запускался.

**(L2) z не action-dependent.** `B_U[0] = B_U[1]`, z определяется
начальным u_0, не историей. Расширение до self-relevant z — отдельный
эксперимент.

**(L3) SNR ∈ [14.5, 29].** Более шумные сенсоры (σ_c ≥ 0.015)
не тестировались в полном прогоне.

**(L4) gru_priv = 8.** Устойчивость к другим размерностям

## Часть 12. Итоговая формулировка

> При наличии приватного сенсорного канала c_x, недоступного
> visual-ветви, auxiliary-супервизия на self-relevant латент
> делает возможной функциональную зависимость policy от этого
> латента. Причинность подтверждена permutation-контролем
> (drop ≥ +0.44, perm ≤ 0.531). Результативность:
> return(B) − return(D) = +0.31, p = 0.00195, n = 10.
> Симметрия s↔w: |return(B) − return(C)| = 0.014, TOST PASS.
> Изоляция: hv → z_* ≤ 0.57. Устойчиво в SNR ∈ [14.5, 29].

**Причина 15 провалов.** В протоколе §4 v5.3.4 `aux = F(o_{0:t})`.
По DPI `I(aux; Z) ≤ I(o_{0:t}; Z)`. Если Z ∉ history — aux не может
его нести, независимо от λ_aux, BPTT, архитектуры, бюджета.

**Устранение.** Добавлен канал c_x, входящий в aux и не входящий
в o/history. DPI обойдён по построению.
